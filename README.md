# بصيرة | Basira
### نظارة ذكية تصف العالم للمكفوفين بالذكاء الاصطناعي
**Smart glasses that describe the world to blind and visually impaired people using AI**

![status](https://img.shields.io/badge/الحالة-قيد_التطوير-yellow) ![platform](https://img.shields.io/badge/Platform-ESP32--CAM%20%7C%20Windows-blue) ![lang](https://img.shields.io/badge/اللغة-العربية-green)

## نبذة عن المشروع
**بصيرة** نظارة ذكية منخفضة التكلفة مثبّت عليها كاميرا لاسلكية صغيرة. يضغط الكفيف زرًا على ذراع النظارة، فتُلتقط صورة لما أمامه وتُرسل إلى برنامج بصيرة على اللابتوب، الذي يحللها بالذكاء الاصطناعي وينطق وصفًا واضحًا **بصوت سعودي** في سماعة بلوتوث بأذن واحدة، فتبقى الأذن الأخرى حرة لسماع ما حوله.

## المشكلة
يواجه المكفوفون وضعاف البصر صعوبة في التعرف على محيطهم والأشياء والنصوص دون مساعدة شخص آخر، مما يحدّ من استقلاليتهم. والأجهزة المساعدة المتوفرة عالميًا مرتفعة السعر ونادرًا ما تدعم العربية واللهجة المحلية.

## الحل
- نظارة تُبنى بقطع متاحة محليًا بتكلفة تقريبية **٣٣٠ – ٥٤٥ ريالًا**.
- وصف فوري للمشهد باللغة العربية وبصوت سعودي طبيعي.
- البرنامج يعمل من **فلاش USB** على أي جهاز ويندوز دون تثبيت.
- خطة بديلة بكاميرا USB سلكية تضمن عمل النظام إذا تعطل البث اللاسلكي.

## كيف يعمل النظام

```
[زر الضغط] ──> [ESP32-CAM على النظارة]
                       │  بث الصورة عبر Wi-Fi
                       ▼
              [برنامج بصيرة على اللابتوب]
                       │  التعرف على المشهد (Google Gemini)
                       ▼
              [تحويل النص إلى صوت عربي]
                       │  Bluetooth
                       ▼
              [سماعة بأذن واحدة للكفيف]
```

النظارة تحمل البطارية ولوحة الشحن والكاميرا والزر فقط، والمعالجة كلها على اللابتوب.

### توصيل الطاقة
```
بطارية 18650 (3.7V) ──> TP4056 + MT3608 (شحن ورفع إلى 5V) ──> ESP32-CAM (5V / GND)
زر الضغط: بين GPIO13 و GND
```

## التقنيات المستخدمة
| المجال | التقنية |
|---|---|
| العتاد | ESP32-CAM (OV2640)، بطارية 18650، TP4056، MT3608، سماعة Bluetooth |
| برمجة الكاميرا | Arduino IDE (C++) |
| التعرف على الصور | Google Gemini API |
| النطق | تحويل النص إلى كلام (TTS) بالعربية |
| الاتصال | Wi-Fi، Bluetooth |
| التشغيل | Windows 10/11 من فلاش USB |

## التشغيل السريع
1. **الكاميرا:** افتح `firmware/` في Arduino IDE، اختر لوحة `AI Thinker ESP32-CAM`، أدخل اسم وكلمة مرور شبكة الجوال، ثم ارفع الكود عبر لوحة ESP32-CAM-MB.
2. **مفتاح Gemini:** أنشئ مفتاحًا مجانيًا من `aistudio.google.com` بحساب Gmail، وضعه في ملف الإعدادات داخل `app/`.
3. **البرنامج:** انسخ مجلد `basira` إلى الفلاش، وشغّل `USB-SETUP.bat` مرة واحدة على جهاز متصل بالإنترنت.
4. **الصوت:** اقرن سماعة البلوتوث باللابتوب واجعلها مخرج الصوت الافتراضي.
5. شغّل البرنامج، واضغط زر النظارة لسماع الوصف.

> ⚠️ يجب أن يكون اللابتوب والكاميرا على نفس الشبكة (نقطة اتصال الجوال).

---

## تنبيهات السلامة
- لا توصل البطارية مباشرة بالكاميرا دون لوحة الرفع، لأن ESP32-CAM يحتاج 5 فولت ثابتة.
- لا تشحن بطارية 18650 دون إشراف، ولا تستخدم بطارية منتفخة أو مخدوشة الغلاف.
- افصل الطاقة قبل أي تعديل، وراجع القطبين قبل التشغيل.
