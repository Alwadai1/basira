# بصيرة | Basira
### نظارة ذكية تصف العالم للمكفوفين بالذكاء الاصطناعي
**Smart glasses that describe the world to blind and visually impaired people using AI**

![status](https://img.shields.io/badge/الحالة-قيد_التطوير-yellow) ![platform](https://img.shields.io/badge/Platform-ESP32--CAM%20%7C%20Mobile-blue) ![lang](https://img.shields.io/badge/اللغة-العربية-green)

## نبذة عن المشروع
**بصيرة** نظارة ذكية منخفضة التكلفة مثبّت عليها كاميرا لاسلكية صغيرة. يضغط الكفيف زرًا على ذراع النظارة، فتُلتقط صورة لما أمامه وتُحلَّل بالذكاء الاصطناعي، ثم ينطق **جوال الكفيف** وصفًا عربيًا واضحًا في سماعة بلوتوث بأذن واحدة، فتبقى الأذن الأخرى حرة لسماع ما حوله.

**لا حاجة إلى لابتوب:** يحمل الكفيف النظارة والجوال الموجود في جيبه فقط.

## المشكلة
يواجه المكفوفون وضعاف البصر صعوبة في التعرف على محيطهم والأشياء والنصوص دون مساعدة شخص آخر، مما يحدّ من استقلاليتهم. والأجهزة المساعدة المتوفرة عالميًا مرتفعة السعر ونادرًا ما تدعم العربية واللهجة المحلية.

## الحل
- نظارة تُبنى بقطع متاحة محليًا بتكلفة تقريبية **٣٣٠ – ٥٤٥ ريالًا**.
- وصف فوري للمشهد باللغة العربية وبصوت سعودي طبيعي.
- يعمل بالنظارة والجوال فقط، دون تطبيق يُثبَّت: صفحة تفتح في متصفح الجوال.
- اللابتوب مع كاميرا USB سلكية خطة احتياطية يوم العرض فقط.

## كيف يعمل النظام

```
[زر الضغط] ──> [ESP32-CAM على النظارة]
                       │  ترسل الصورة بنفسها عبر إنترنت نقطة اتصال الجوال
                       ▼
                [Google Gemini]
                       │  يعيد وصفًا عربيًا قصيرًا
                       ▼
            [ESP32-CAM ← صفحة بصيرة في متصفح الجوال]
                       │  نطق عربي (ar-SA) عبر Bluetooth
                       ▼
              [سماعة بأذن واحدة للكفيف]
```

النظارة تحمل البطارية ولوحة الشحن والكاميرا والزر، وتتولى الكاميرا إرسال الصورة واستقبال الوصف بنفسها. الجوال يوفر الإنترنت وينطق الوصف.

### توصيل الطاقة
```
بطارية 18650 (3.7V) ──> TP4056 + MT3608 (شحن ورفع إلى 5V) ──> ESP32-CAM (5V / GND)
زر الضغط: بين GPIO13 و GND
```

## التقنيات المستخدمة
| المجال | التقنية |
|---|---|
| العتاد | ESP32-CAM (OV2640)، بطارية 18650، TP4056، MT3608، سماعة Bluetooth |
| برمجة الكاميرا | Arduino IDE (C++) |
| التعرف على الصور | Google Gemini API |
| النطق | Web Speech API في متصفح الجوال (صوت عربي ar-SA) |
| الاتصال | Wi-Fi، Bluetooth |
| التشغيل | أي جوال Android أو iPhone بمتصفح Chrome أو Safari |

## التشغيل السريع
1. **مفتاح Gemini:** أنشئ مفتاحًا مجانيًا من `aistudio.google.com` بحساب Gmail.
2. **الإعدادات:** انسخ `firmware/basira/config.example.h` باسم `config.h`، واكتب فيه اسم نقطة اتصال الجوال وكلمة مرورها والمفتاح.
3. **الرفع:** افتح `firmware/basira/basira.ino` في Arduino IDE، اختر لوحة `AI Thinker ESP32-CAM` مع تفعيل PSRAM، وارفع الكود عبر لوحة ESP32-CAM-MB.
4. **الجوال:** شغّل نقطة الاتصال، وافتح عنوان النظارة الظاهر في Serial Monitor في المتصفح، واضغط **ابدأ** مرة واحدة.
5. **الصوت:** اقرن سماعة البلوتوث بالجوال، ثم اضغط زر النظارة لسماع الوصف.

> ⚠️ اجعل شاشة الجوال تعمل أثناء الاستخدام، فالمتصفح يوقف الصفحة عند قفل الشاشة.
> 🔒 ملف `config.h` مستثنى من GitHub حتى لا ينكشف مفتاح Gemini.

تفاصيل أكثر في [firmware/README.md](firmware/README.md).

## تنبيهات السلامة
- لا توصل البطارية مباشرة بالكاميرا دون لوحة الرفع، لأن ESP32-CAM يحتاج 5 فولت ثابتة.
- لا تشحن بطارية 18650 دون إشراف، ولا تستخدم بطارية منتفخة أو مخدوشة الغلاف.
- افصل الطاقة قبل أي تعديل، وراجع القطبين قبل التشغيل.

## خارطة الطريق
| المرحلة | ما يتغير | دور الجوال |
|---|---|---|
| **١. النسخة الحالية** ✅ | النظارة تصوّر وترسل الصورة إلى Gemini بنفسها | الإنترنت + نطق الوصف |
| **٢. نسخة تنطق بنفسها** | لوحة أقوى (ESP32-S3) مع مكبر صوت صغير أو سماعة توصيل عظمي قرب الأذن | الإنترنت فقط |
| **٣. نسخة بشريحة اتصال** | وحدة 4G بشريحة بيانات وبطارية أكبر | لا حاجة للجوال |
| **٤. وضع أوفلاين أساسي** | تعرّف محلي على أشياء محدودة (شخص، باب، سيارة، درج) مع تنبيهات صوتية مسجلة، والوصف التفصيلي عند توفر الإنترنت | لا حاجة للجوال ولا للإنترنت للتنبيهات الأساسية |

**لماذا لا تعمل النسخة الحالية دون جوال؟** لوحة ESP32-CAM ليس فيها مخرج صوت، وذاكرتها لا تتسع لتشغيل الكاميرا والواي فاي والتشفير والبلوتوث معًا. ووصف المشهد بالعربية يحتاج نموذج ذكاء اصطناعي كبيرًا لا يعمل على لوحة صغيرة.
