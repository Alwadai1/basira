# كود النظارة (ESP32-CAM)

النسخة الحالية تعمل **بالنظارة والجوال فقط** دون لابتوب.

## الملفات
| الملف | الوظيفة |
|---|---|
| `basira/basira.ino` | الكود الرئيسي: الزر، الكاميرا، الإرسال إلى Gemini، وخادم صفحة الجوال |
| `basira/page.h` | صفحة بصيرة التي تفتح في متصفح الجوال وتنطق الوصف |
| `basira/config.example.h` | نموذج الإعدادات؛ انسخه باسم `config.h` |

## خطوات الرفع
1. ثبّت دعم ESP32 في Arduino IDE (Boards Manager ← esp32 by Espressif).
2. انسخ `config.example.h` باسم `config.h`، واكتب فيه اسم نقطة اتصال الجوال وكلمة مرورها ومفتاح Gemini.
3. الإعدادات: Board **AI Thinker ESP32-CAM** · PSRAM **Enabled** · Partition **Huge APP**.
4. ركّب اللوحة على ESP32-CAM-MB، ووصّلها بكيبل بيانات، ثم Upload.
5. افتح Serial Monitor على 115200 لترى عنوان الصفحة، مثل `http://192.168.43.120`.

## الاستخدام
1. شغّل نقطة الاتصال في الجوال، ثم شغّل النظارة.
2. افتح العنوان في متصفح الجوال (Chrome أو Safari)، واضغط **ابدأ** مرة واحدة.
3. اقرن سماعة البلوتوث بالجوال.
4. اضغط زر النظارة: تسمع «لحظة» ثم الوصف خلال ثوانٍ.

## ملاحظات
- اجعل شاشة الجوال تعمل طوال التجربة (زِد مدة إطفاء الشاشة)، لأن المتصفح يوقف الصفحة عند قفل الجوال.
- زر **ماذا ترى الكاميرا؟** يعرض الصورة الحالية، ويفيد في ضبط زاوية الكاميرا على النظارة.
- النسخة تجريبية وتتخطى فحص شهادة HTTPS؛ تحسينها بإضافة شهادة Google الجذرية خطوة مقترحة لاحقًا.
